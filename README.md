# AR 전파장애물 — 설치 파일

안드로이드 앱 **AR 전파장애물**(`kr.chan3.arcam`)의 설치 파일(APK)만 올리는 저장소입니다. 소스 코드는 비공개입니다.

**최신 버전 받기: [arcam.apk](https://github.com/chelly1221/arcam-releases/releases/latest/download/arcam.apk)**

- 앱은 열 때마다 이 저장소의 최신 릴리스를 확인해 새 버전을 알려 주고, ‘업데이트’를 누르면 바로 내려받아 설치합니다
  (처음 한 번 ‘알 수 없는 앱 설치’ 허용 필요. 안드로이드 12 이상은 확인창 없이 설치).
- 릴리스마다 `arcam.apk`와 `version.json`(versionCode·versionName·SHA-256·크기·변경 내용)이 있습니다. 앱은 크기와 SHA-256을 확인한 뒤 설치합니다.
- 모든 APK는 같은 키로 서명됩니다 — 인증서 SHA-256 `934c20310a451b0b5e9fbf9dfb547cc438775f167c0843677f9541de15e0329f`.
  다른 키로 서명된 파일은 설치된 앱 위에 설치되지 않습니다.
